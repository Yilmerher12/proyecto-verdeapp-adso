# Comentario de cierre de semana en el issue

Al terminar la semana, quien tenía el issue copia este bloque como **comentario en ese mismo issue** y lo llena. Aplica aunque la tarjeta esté terminada.

## Para qué sirve

- Si la tarjeta no se terminó, es lo que usa la persona que la continúa para saber por dónde seguir.
- El Scrum Master lo usa para escribir el informe semanal (ver el [`README.md`](README.md) de esta carpeta).
- Deja en el propio issue el historial de qué pasó cada semana.

## Antes de publicarlo

Si la tarjeta no está terminada, haz `push` de tu rama para que quien siga encuentre tu trabajo. Quien continúa trabaja en esa misma rama.

## Bloque para copiar

```
## Cierre de la semana NN — @usuario

**Estado:** Terminada / En progreso / Bloqueada
**Rama y PR:** `prefijo/nombre-de-la-rama` — enlace al PR (o "sin PR todavía")
**Tiempo usado:** unas N horas de las 10 de la semana

**Qué completé:**
-

**Qué falta:**
-

**Lo que descubrí:** decisiones que tomé o cosas que no esperaba.
-

**Bloqueos:**
-

**Para quien siga:** por dónde empezar, qué archivos tocar y qué comandos correr (por ejemplo, si hay una migración que aplicar).
```
